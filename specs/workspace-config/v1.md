# 工作区配置 v1（`.dshpkcfg`）

> 状态：**现行（v1 · r2 增补导出旋钮）**。`.dshpkcfg` 是 PackForge 桌面端在**导出流程**中持久化的「导出工作区快照」——保存导出参数（整合包名 / 版本 / 作者 / 内容开关 / 输出目录等），下次「读取」恢复，避免重复填写。属于**工具本地持久化，不进入整合包**。
>
> 关联：`../pack-structure/v1.md`（安全过滤清单，`.dshpkcfg` 命中 `DENY` 精确名排除）、`../pack-structure/v3.md`（`.dspack` 容器，打包时排除）、`../manifest/v5.md`（`name` / `version` / `displayName` / `author` / `icon` / `dshVersion` / `dshVersions` / `launchers` 与 manifest 字段对应；vendoring 选项对应 `vendored{}` 打包行为，见 `../pack-structure/v3.md` §8.6）。

## 概述

`.dshpkcfg` 是 PackForge 桌面端在**导出流程**中持久化的「导出工作区快照」——把当前导出参数（整合包名、版本、作者、内容开关、输出目录等）保存下来，之后点「读取」恢复，避免重复填写。

- 属于**工具本地**持久化，**不进入整合包**：打包时命中安全过滤清单（`DENY` 精确名），与凭据/运行时状态一同排除。
- 一个目录一份；由**所在目录**区分形态，文件内**无** `kind` 字段。

## 位置

| 形态 | 路径 |
|---|---|
| Profile 导出 | `<profilesRoot>/<profile>/.dshpkcfg`（默认 `~/.dsh/profiles/<profile>/.dshpkcfg`） |
| DSH_HOME 导出 | `<home>/.dshpkcfg`（默认 `~/.dsh/.dshpkcfg`） |

## 编码与结构

- UTF-8，单个 JSON 对象。
- 序列化：`JSON.stringify(obj, null, 2)`（2 空格缩进，结尾换行 `\n`）。
- 空值约定：字符串字段以空串 `""` 表示「未填写」；读取端对空串视为未设置（不回填，保留表单默认值）。

## 公共字段（两种形态皆有）

| 字段 | 类型 | 含义 |
|---|---|---|
| `name` | string | 整合包名称（manifest `name`）；空 = 用 Profile/home 名 |
| `version` | string | 版本号；空 = 默认 `1.0.0` |
| `displayName` | string | 展示名；空 = 用 Profile/home 名 |
| `description` | string | 一句话描述 |
| `author` | string | 作者 |
| `icon` | string | 图标（URL 或路径） |
| `dshVersion` | string | 钉定的 DSH 版本；空 = 取最新已装 |
| `dshVersions` | string[] | **r2**：实测兼容集（已装版本多选；**首个即首选**，与 `dshVersion` 对应）；缺省 = 仅 `dshVersion` 单选 |
| `vendor` | string | **r2**：vendoring 档位：`auto`（默认，§8.6 三态探测自动内嵌）/ `off`（禁用）/ `full`（全量收集传递闭包 = 离线可装形态） |
| `launchers` | object | **r2**：启动器兼容声明，与 manifest v5 §14 `launchers` **同构**（`id → 简式 \| 全式`），导出时原样写入 manifest；缺省 = 通用包 |
| `out` | string | 输出目录；空 = 当前目录 |
| `exportContent` | object | 上一级目录内容的分类开关（见下） |

### `exportContent`

导出上一级目录（DSH_HOME）内容时的布尔开关：

| 字段 | 含义 |
|---|---|
| `skill` | 导出 `skills/` |
| `preset` | 导出 `.agent-presets/` |
| `instruction` | 导出 `AGENTS.md`（全局指令） |
| `data` | 导出 `data/`（仅 DSH_HOME 形态） |

## Profile 形态专用字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `profileName` | string | 安装名（覆盖 manifest `profileName`） |
| `mode` | string | 导出形态：`dspack`（单文件）\| `repo`（源形态） |
| `content` | string | 仓库内容档：`manifest` \| `readme` \| `full`（仅 `mode=repo` 有意义） |

## DSH_HOME 形态专用字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `defaultProfile` | string | 默认 Profile；空 = 字母序第一个 |

## 生命周期

1. **保存**：「保存」/「保存并导出」按钮 → `saveCfg(dir, config)` 写入 `.dshpkcfg`。
2. **读取**：「读取」按钮，或切换 Profile / home 时自动加载 → `loadCfg(dir)` 读回并回填表单。
3. **排除**：打包（`.dspack` 容器，见 `../pack-structure/v3.md`）时 `.dshpkcfg` 命中安全过滤清单，不进包。

## 兼容性

- 当前**无** `schemaVersion` 字段（隐式 v1）。读取端容错：`JSON.parse` 失败返回 `null`；缺失字段视为未设置。
- 演进约定：未来新增字段时应引入 `schemaVersion`；无版本号的旧文件一律按 v1 处理。
- **r2 增补字段**（`dshVersions` / `vendor` / `launchers`）均为可选增量：旧读取端按「缺失字段视为未设置」忽略（等价 `auto` / 单选 / 通用包）；新读取端读旧文件同样安全。`.dshpkcfg` 本就不进整合包，无包级兼容问题。
